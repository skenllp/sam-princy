Sam & Princy — Wedding Invitation Website
=========================================

Keep index.html and the "assets" folder together. Open index.html in a browser
to preview, or upload the whole folder to any static host (Netlify, Vercel,
GitHub Pages). No build step is needed.

Sections: opening curtain gate, hero, couple + invitation wording, Save the Date
(large "8 · February 2027"), wedding ceremony, groom's party
departure, families, closing.

assets/couple.jpeg   Couple illustration (from the groom's-party PDF).
assets/og-image.jpg  Link-preview image for WhatsApp/social sharing.
assets/music.mp3     Wedding song (tap the note icon, bottom-right; never autoplays).

Share preview tags in <head> point to https://sam-princy.vercel.app/ — change
those two values if you deploy at a different address.
The ceremony "View on Map" button is a Google Maps search for St. Sebastian
Church, Pallithodu, Cherthala; replace it with an exact pin link if you have one.
